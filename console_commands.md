# Console commands

Before executing below commands it's better to enter console as `postgres` user: `su - postgres`.

- `psql` - run PostgreSQL console
- `createdb mydb` - create database
- `dropdb mydb` - drop database
- `createuser kenny` - create user
- `dropuser kenny` - drop user `kenny`
- `pg_config` - show DB config
- `vacuumdb app_db` - vacuum database
- `reindexdb` - reindexdb is a utility for rebuilding indexes in a PostgreSQL database. It's a wrapper around the SQL command `REINDEX`
